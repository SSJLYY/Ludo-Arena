## 第一部分 · 规则裁定（引擎权威语义）

### 1.1 初始决策点落地（架构设计文档的 4 个待确认项）

| 决策点 | 采信方案 | 实现位置 |
|---|---|---|
| 主体资质 | 非代码决策：个人主体无法上架游戏类目，红字提醒留在 README；开发/体验版不受影响 | `README.md` |
| 终点规则 | **两种都实现**：`needExactFinish` 切换，默认精确到达；弹回路径会经过 57 再折返 | `engine/move.js planMove` |
| 规则范围 | v1 起飞/撞子/叠子/同色跳格(+4)/安全格/精确到达/托管；飞行箭头(+12)、道具卡、观战席 v1.1 起加入 | `engine/*` |
| AI 默认难度 | 普通（2），快速开始与建房默认一致，可切简单/困难/大师 | `roomCreate` / `hall` |

### 1.2 主干规则裁定（两版引擎共同遵守）

1. **主环配色与跳格**：每色 13 格、严格间隔 4 格（落己色 → 跳下一同色格恰为 +4）。起飞点绝对格 `[51, 12, 25, 38]`（红/黄/蓝/绿），使起飞点与归航道口相邻且必为己色——棋盘几何与规则互相锁死，测试校验一致性。
2. **跳格不连锁**：落己色格只跳一次；若 +4 会越过归航道口（rp+4 > 51）则不跳。
3. **起飞即跳**：起飞点必为己色，起飞后同样触发 +4 跳格。
4. **撞子只看最终落点**：跳格/飞跃越过格上的敌机不受影响；落点是安全格（四角起飞点）则不撞。
5. **叠子可被撞**：落点踩中敌方叠子，叠子全体回基地、记多次击杀。
6. **连掷三个 6**：第 3 个 6 不产生移动、不获奖励掷，本回合立即作废换人（不回退此前的移动）。
7. **无子可动**：自动跳过并换人，不保留奖励掷骰。
8. **奖励掷骰不叠加**：掷 6 与撞子同一手发生时只给 1 次额外掷骰。
9. **胜负**：首家 4 机到齐即终局（`finishRank=1`），其余按总进度（各机 rp 之和）排 2-4 名。**2v2 团队赛按队伍判胜：`winner` 存队伍号且同步 `winnerTeam`，绝不能拿 `ranking[0]`（座位号）**——select / accel / forceEndByRound 三处口径必须一致（v33 铁律，见第三部分）。
10. **飞行箭头**：每色 rp 36 的己色格飞跃 12 格至 rp 48；不连锁、只判最终落点撞子；房间开关 `allowFly`。
11. **网页版道具卡（4 种，与小程序的 2 种不同）**：🧨炸弹（炸毁敌机，安全格免疫）/ 🛡护盾（被撞时抵消一次，进攻方反震回基地）/ ⚡加速（前进 4 格，**必须先过 `computeLegalMoves` 校验**，否则精确到达模式会越界抛异常）/ 🔀换位。局内命中敌机随机得卡或商城购买。
12. **托管语义**：掉线 30s 或**对局中主动离开**都转 AI 托管（`type='ai', hosted=true`，昵称加「(托管)」），绝不置空座位——置空会让 `switchPlayer` 停在无人座位导致整局卡死。
13. **自定义规则（网页版 v13）**：`takeoffAny`（任意点数起飞）/ `crashBack=false`（和平共存）/ `roundLimit`（超时按各机 rp 总进度判胜）/ `turbo`（AI 步频 220ms）/ `diceMode`（1/2/3 骰）/ `seriesRounds`（系列赛局数）。房主开局前在规则面板修改，开局后锁定。
14. **AI 风格**：`hostStyle`（aggressive/balanced/defensive）映射到 `game.players[seat].aiStyle`，影响 `scoreMove` 权重；普通以上档位持重掷卡且候选全负分时自动重掷；带盾目标重罚（AI 不踩盾）。

### 1.3 与架构文档的结构差异（小程序版）

| 文档 | 实现 | 原因 |
|---|---|---|
| `services/room.js` + `game.js` | 合并为 `services/api.js` | 均为云函数薄封装，避免空壳 |
| 云函数 `common/` 软链 | `tools/sync-engine.js` 复制脚本 + `gameAction/engine/` 副本 | Windows 软链需管理员权限；云函数按目录隔离打包 |
| 新增 `login` / `getWxacode` 云函数 | 已实现 | openId 获取 / 海报小程序码（文档未列出但必需） |
| `allowStack` 设置项 | 数据结构保留，规则恒为允许叠子 | 开关无实际语义 |

### 1.4 网页版关键工程约定（与小程序不同的部分）

| 事项 | 约定 | 原因 |
|---|---|---|
| 持久化 | **JSON 原子写**（tmp→rename），禁止 SQLite/文件锁 | 宿主 CentOS 7（glibc 2.17）编不了 Node 原生模块 |
| 写盘成本 | 整文件 stringify+rename+copy `.bak`，**批量操作必须合并落盘**（如 `pushMailBatch`），勿在循环里 save() | 一局 4 人曾产生 5 次全量写盘，v33 修复 |
| 扩容 | **单实例，禁止 cluster/多副本** | `ensureFresh` 靠 mtime 重载，多进程互相覆盖丢数据 |
| 部署 | 必须走 `deploy.sh` 的 docker build 重建，**禁 docker cp**（会嵌套 src/src 致代码不更新） | 容器目录结构约束 |
| 短凭证 | 别给 `verifySecret` 加凭证长度限制 | 存量测试/脚本用 't1'、'a-tok' 等 2-5 位短凭证 |
| 每日任务 | `recordGame` 内 `bumpDaily()` 必须在玩家对象回写 `data.players` **之后**调用 | 放前面新玩家首局丢进度 |
| 广播快照 | `publicGame` 不含 `roundNo`（被裁剪），WS 测试用 `currentSeat` 变化做推进判据 | 快照瘦身的历史裁定 |

### v33 稳定性大修（2026-09-08 审查 + 修复，已部署）

> 全量代码审查发现 5 个 P0、6 个 P1，全部修复：

**P0**
1. **accel 道具可崩进程**：useItem 的 accel 分支直接 `applyMove(...,4)` 不校验，精确到达模式越界 throw MOVE_EXCEEDS_HOME，且全项目无兜底 → 进程退出。修复：先 `computeLegalMoves` 校验 + index.js 加 uncaughtException/unhandledRejection 兜底（记审计不退出）+ SIGTERM 前 flushAll。
2. **团队赛 accel 误判胜负**：拿 `ranking[0]`（座位号）当 winner。修复：统一按 `doneTeam` 判定（winner/winnerTeam 均为队伍号）。
3. **每日任务永远完不成**：recordGame 只调 bumpWeekly 从不累加 daily。修复：新增 `bumpDaily()` 且在玩家对象回写**之后**调用。
4. **对局中 leave 卡死回合**：置 `type='empty'` 导致 switchPlayer 停在无人座位。修复：转 AI 托管（websocket leave 与 room-manager.leaveRoom 同口径）。
5. 进程级兜底（同 1）。

**P1**：leaveRoom 先取 clientId 再删（原顺序删不掉）；forceEndByRound 团队赛按队伍进度取优；金额校验 `normAmount`（awardCoins/Diamonds 只收非负整数）；**批量邮件 `pushMailBatch`**（4 人局从 5 次全量写盘降为 1 次）；banner url/color 白名单净化（存储型 XSS 入口）；公会 50 人上限；凭证认领追溯（`secretSetAt` + 后台 secret-info）；**SW 重写**（/api 不缓存、只缓存 res.ok、静态 SWR、上限 60 条）；Dockerfile HEALTHCHECK + NODE_ENV=production。

**运维**：**异地备份** `tools/pull-backup.sh`（拉服务器最新备份到本地 `backups-local/` 并自动验证）；回放索引保留 50 → **100 局**（`REPLAY_KEEP` 可调，战报回放直达窗口翻倍）；每日 09:00 服务器体检自动化（health/磁盘/内存/异地备份，异常主动报告）。
**测试**：`test-v33.js` 26 项 + `test-leave-host.js` 7 项。

## 第三部分 · 稳定性铁律（v33 审查沉淀，改动前必读）

1. 🔴 引擎任何**可抛异常的调用点必须在 WS/HTTP 层 try/catch**（`applyMove` 越界会 throw MOVE_EXCEEDS_HOME；`useItem(accel)` 必须先 `computeLegalMoves` 校验）。
2. 🔴 **团队赛判胜口径**：winner 存队伍号 + 同步 `winnerTeam`，绝不能拿 `ranking[0]`；select/accel/forceEndByRound 三处一致。
3. 🔴 对局中「离开/掉线」必须**转 AI 托管**，置空座位会卡死整局。
4. 🔴 `bumpDaily()` 必须在玩家对象回写之后调用。
5. 🔴 批量操作必须**合并落盘**（写盘 = 全量 stringify+rename+copy，很贵）。
6. 🔴 单实例前提：**禁止 cluster/多副本**。
7. 🔴 别给 verifySecret 加凭证长度限制（存量测试用短凭证）。
8. 改棋盘几何先读两旋转约定：`rot([c,r])` 用 `(GRID-1)-r`，`rotBox` 用 `GRID-r-h`（13 vs 14），两旋转别混。
9. 自检命令：`node -e "global.window={};require('./public/js/board.js')"`（取 `global.window.Board`）。
