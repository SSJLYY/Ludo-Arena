# 小程序版部署指南（已冻结 🧊，供复活时使用）

> 小程序线 v1.19.2 后冻结。本文保留自旧版 README 的完整部署步骤，如需恢复小程序线按此操作；架构原理见 [架构设计.md](架构设计.md)。

## 1. 基本信息

- `project.config.json`：把 `appid` 从 `touristappid` 换成你的小程序 AppID。
- **主体资质提醒（🔴 卡死项）**：个人主体无法上架「游戏」类目，需企业或个体工商户主体；开发/体验版不受影响。

## 2. 云开发环境

1. 微信开发者工具 →「云开发」→ 开通并记下环境 ID。
2. `miniprogram/app.js` 顶部 `const CLOUD_ENV = ''` 填入环境 ID（单环境可留空）。

## 3. 数据库（5 个集合 + 安全规则 + 索引）

在云开发控制台「数据库」创建集合：`rooms`、`games`、`moves`、`users`、`room_auth`。

- `rooms` / `games` / `moves`：权限设为**自定义安全规则**（客户端只读，写入全部走云函数）：

```json
{ "read": true, "write": false }
```

- `users`（用户资料与战绩）：**只能读自己的文档**，防止用户资料被枚举：

```json
{ "read": "doc._id == auth.openid", "write": false }
```

- `room_auth`（房间密码凭证）：客户端**完全不可读写**：

```json
{ "read": false, "write": false }
```

> 实时 `watch` 依赖读权限；写权限关闭后即使前端被篡改也无法直接改库，权威状态只在云函数侧。

索引：`rooms` 集合给 `roomNo` 建**唯一索引**，`status + createdAt` 组合索引（其余集合 v1 可不建）。

## 4. 部署云函数

在开发者工具 `cloudfunctions/` 下，对以下 12 个函数右键「上传并部署（云端安装依赖）」：

```
login  roomCreate  roomJoin  roomSeat  roomLeave  roomEmote
gameStart  gameAction  gameHeartbeat  getLeaderboard  getWxacode  aiTick
```

> 注意：
> - 每次修改 `miniprogram/engine/` 后，先执行 `node tools/sync-engine.js` 再重新上传 `gameAction`、`gameStart`、`aiTick`。
> - `login`、`roomJoin` 内含 `sec.js`（msgSecCheck 共享模块），sync 脚本会保持两份一致；`config.json` 已声明 openapi 权限。
> - `aiTick` 的 `config.json` 含定时触发器（每 30 秒）：**必须部署该函数**，全离线时 AI 对局才会自动推进。
> - 未发布版本调用 `msgSecCheck` / `wxacode` 可能报错，代码已容错（昵称放行、海报无码）。

## 5. 验证

1. 模拟器打开 →「快速开始」→ 应直接进入对局并与 3 个 AI 完整打完一局。
2. 两台手机建房互加，验证实时座位同步与对局推送。
3. 对局中杀掉小程序进程 30 秒后，其余玩家应看到「托管」标记继续对局；重新进入后自动接管。

## 6. 本地测试

```bash
node tests/run-tests.js        # 引擎 40416 项断言 + 1000 局模拟
node tests/run-cloud-tests.js  # 云函数集成 2258 项断言
npm run bench                  # AI 平衡性 + 性能基准
npm run check:wxml             # WXML 静态检查（真机编译防回归）
```

## 7. 云函数接口与错误码

| 函数 | 入参 | 出参 |
|---|---|---|
| `login` | `{nickName?, avatarUrl?}` | `{openId, user}` |
| `roomCreate` | `{password?, settings?, quick?, profile?}` | `{roomId, roomNo}` |
| `roomJoin` | `{roomId?\|roomNo?, password?, profile?}` | `{roomId, seatIndex}` / `{spectator: true}` |
| `roomSeat` | `{roomId, seatIndex, action, aiLevel?}` | `{seats}`（action 含 takeover 观战者接管） |
| `roomLeave` | `{roomId}` | `{seatIndex, hosted?, dissolved?}` |
| `gameStart` | `{roomId}` | `{gameId}` |
| `gameAction` | `{gameId, action, payload?, seq?}` | `{seq, events?}` |
| `gameHeartbeat` | `{roomId, hosted?}` | `{seat}`（hosted 为主动托管开关） |
| `roomEmote` | `{roomId, type}` | `{ok}` |
| `getLeaderboard` | `{}` | `{rows, myRank, me}` |
| `getWxacode` | `{roomId}` | `{fileID}` |
| `aiTick` | 定时器自动触发 | `{scanned, advanced}` |

错误码：`SEQ_CONFLICT` / `ROOM_FULL` / `ROOM_NOT_FOUND` / `ROOM_STARTED` / `WRONG_PASSWORD` / `LOCKED` / `NOT_YOUR_TURN` / `PLANE_NOT_MOVABLE` / `NOT_ENOUGH_PLAYERS` / `NOT_OWNER` / `GAME_ENDED`（客户端在 `utils/cloud.js` 统一转文案）。
