## 功能总览（网页版）

### 🎲 玩法

| 模块 | 能力 |
|---|---|
| 房间 | 建房（密码 / 规则开关）、房号或邀请链接加入、二维码进房、快速开始（1 人 + 3 AI）、自动匹配（25 秒无人兜底提示人机）、观战（画面延迟 2.5 秒防偷跑，观战者可接管 AI 座位） |

### 🔐 安全

| 层 | 措施 |
|---|---|
| 账号 | 32 位本机凭证（localStorage），16 个财富/社交端点校验，冒名转账/冒名建房直接拒绝；昵称占用保护（NICK_TAKEN） |
| 防刷 | 全部资损入口限频 + 每日上限；建房/加入防洪水；房间密码错误锁定 |

## 技术栈与架构

```
浏览器（原生 JS + Canvas 2D，零构建，PWA）
   │ WebSocket（ws://host/ws）          │ HTTP API
   ▼                                    ▼
Node.js 单进程（Docker node:24-alpine）
├── Express（HTTP API + 静态资源 + gzip）
├── ws（WebSocket 房间/对局推送）
├── game-engine/（规则引擎，与小程序版同源）
└── JSON 原子写持久化（stats/meta/rooms/announce）
```

- **服务端权威**：骰子随机数、规则判定全在服务端，客户端只发意图
- **为何 JSON 而非 SQLite**：部署宿主 CentOS 7（glibc 2.17）无法编译 Node 原生模块，持久化统一 JSON 原子写；单实例架构（禁止 cluster 多进程，会互相覆盖数据）
- **前端零构建**：三视图单页（大厅/房间/对局）+ `js/{app,api,board,i18n,qr,fx,pwa}.js`，中英双语（i18n）
- 规则核心：主环 52 格 + 归航道 5 格 + 终点 rp=57；掷 6 起飞（连 3 个 6 作废）；撞子回基地；同色跳格 +4；飞行箭头 +12；四角安全格；终点精确到达

## 快速开始

### 本地运行

```bash
cd server
npm install
npm start                 # 默认 :3000，浏览器打开 http://localhost:3000
```

可选环境变量：`PORT`（默认 3000）、`ADMIN_TOKEN`（后台令牌，本地经 `.env.local` 注入，不入库）、`STATS_DIR`（数据目录）、`AI_STEP_DELAY`（AI 步频 ms，正式 700 / 测试 20）、`SPECTATE_DELAY_MS`（观战延迟，默认 2500，0=关闭）。

### 测试

```bash
npm run test:web     # 网页版全量 13 步：11 专项（凭证/防刷/占用/榜单/战报/锦标赛/后台/防爆破…，202 项断言）
                     # + 1000 局 AI 自对弈 + 集成 e2e
                     # ⚠️ integration/test-leave-host 需本机 :3000 已起服务且端口空闲
node tests/test-client-error.js && node tests/test-social.js && node tests/test-v33.js
                     # 3 个未入 test:web 链的独立专项（241 = 上述 202 + 这三项 39）
npm test             # 引擎单元测试（与小程序共用）：40416 项断言 + 1000 局模拟
npm run test:cloud   # 小程序云函数集成测试（内存模拟器）：2258 项断言
npm run bench        # AI 平衡性 + 引擎性能基准
npm run verify:backup   # 备份可恢复性验证
npm run load         # 容量压测（模拟 N 观战客户端 + 轮询读放大）
```

> 2026-09-28 实测：14 个自包含专项 241 项断言全绿；self-play 1000/1000 局收敛（平均 266.6 回合/局）；引擎 40416 项全过；云集成 2258 项全过。

### 部署（腾讯云 129.211.29.228）

```bash
bash deploy.sh
```

流程：打包 `server/` → scp 上传 → 服务器解包 → `docker build`（node:24-alpine）→ 重启容器（80+3000 双端口映射，数据卷 `/opt/flychess-data`）→ 自动冒烟（health/静态资源/social/identity/boards/mail/tournament 等约 20 项探针）。

注意：

- 🔴 **必须走 `deploy.sh` 的 docker build 重建**，禁用 `docker cp`（会嵌套 src/src 导致代码不更新）
- 🔴 禁用 SQLite / 文件锁（宿主 glibc 过老），一律 JSON 原子写
- 🔴 单实例前提：mtime 重载机制，**禁止 cluster/多副本扩容**（会互相覆盖丢数据）
- Docker 日志已限轮转（10MB × 3），Dockerfile 含 HEALTHCHECK

## 已知取舍与限制

- 排行榜取自内存排序，数据量大后需为 `stats.wins` 建索引（查询写法已预留）
- AI 每步 JSON 深拷贝保证引擎纯函数语义（前后端共用），单局成本可忽略；如做大规模对局数需评估
- 观战延迟 2.5s 期间观战者看到的画面滞后，属防偷跑的预期行为
- 段位为纯展示，不计负场衰减、无匹配分
- 微信支付为脚手架（未配商户号时优雅返回 PAY_NOT_CONFIGURED，不做假支付）
